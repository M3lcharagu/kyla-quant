## Replace checkout links

Every CTA uses the literal href placeholder YOUR_CHECKOUT_URL. Before launch, create each product in Gumroad, Payhip, Lemon Squeezy, or another checkout provider. Replace every occurrence of YOUR_CHECKOUT_URL in the matching index.html with the live checkout URL, keeping the href attribute intact. Test each link on mobile, desktop, and in a private browser window.

## Launch notes

Publish each index.html as a static page or paste it into a storefront page. Upload the matching README as the customer download, or export it to PDF. Add a cover image, preview, support email, refund policy, and final product metadata in the checkout platform. Keep prices at $12 and $19 unless the storefront changes; if changed, update the page copy too. Do not promise income, trading performance, rankings, or guaranteed outcomes. The trading pack is educational and not financial advice. Run a final link, accessibility, spelling, download, and mobile test before launch.
