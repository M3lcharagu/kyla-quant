# Local business template kit

A dependency-free, mobile-first static starter for a salon or restaurant. Duplicate `index.html` and `styles.css` per client, then replace the business name, copy, services, hours, contact details, WhatsApp link, and address.

Before publishing:

1. Replace both generic WhatsApp links with the client's verified `https://wa.me/<country-code-and-number>` link.
2. Replace the map placeholder with the client's verified Google Maps embed code; this starter intentionally contains no fabricated real map URL.
3. Confirm all prices, opening hours, consent, image rights, and contact details with the client.
4. Keep the visible offer positioning: **9,000 KSH / 3-day turnaround** unless the client-approved package changes.

There is no framework, build step, analytics script, or external stylesheet requirement.
