# Strategy library — real multi-market scan

This file is generated by the push-triggered workflow from live, key-free OHLCV data. It is intentionally not populated with invented metrics. The workflow runs `python scripts/strategy_factory.py --scan --limit 3000 --output docs/STRATEGY_LIBRARY.md` and commits the resulting complete symbol × timeframe × strategy table.

Verdict rules: **PASS** requires profit factor > 1.15, win rate ≥ 45%, net profit > 0, and at least 50 completed trades. **FAIL** means sufficient data but criteria are not met; **INCONCLUSIVE** means fewer than 50 completed trades or unavailable data. Costs are 0.0002 per side.
